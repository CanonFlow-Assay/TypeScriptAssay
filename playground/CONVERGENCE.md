# Playground convergence — phase 1

The reservation specimen already carries the portable core: unknown transport
data is decoded at the boundary, readonly discriminated-union decisions remain
pure, and mutation evidence stays separate from the TypeScriptAssay receipt.

The next safe increment is a small configuration firewall for an application
adapter: parse named settings to immutable validated values or explicit issues,
with no defaulting. Reuse the existing pinned compiler, `npm run test:playground`
and fresh ignored artifacts. Do not turn the assay's `.tsassay.json` policy into
an application DSL, infer runtime behavior from compilation, or let advice alter
a verifier verdict. Versioned HTTP ingress and generated serializers wait for a
real application boundary and a separately stated contract.
